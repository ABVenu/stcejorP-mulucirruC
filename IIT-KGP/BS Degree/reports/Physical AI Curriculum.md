# Programme Structure

A 141-credit, eight-semester programme of 47 courses. Each course is 3 credits. Semesters 1 to 7 have six courses. Semester 8 has five.

Intelligence and robotics appear in every semester. The fourth year is where autonomous intelligence becomes specialist.

## YEAR 1

### **Foundations of Intelligence and Machines**

Mathematics, Python, object-oriented programming, a first learning course, the physics of motion, and a first course in AI and robotics.

## YEAR 2

### **Learning Systems and Motion**

Machine learning, deep learning, differential equations, robot mechanics, applied control, software engineering, and simulation of robotic systems.

## YEAR 3

### **Applied Artificial Intelligence**

Computer vision, 3D data, natural language and generative AI, real-time systems, sensor fusion, and the two projects that carry a job application.

## YEAR 4

### **Autonomous Intelligence**

A policy, a model that turns an image and a task into a command, efficient AI software, and one simulated mission on an autonomous machine.

# Course Curriculum

## YEAR 1 — Foundations of Intelligence and Machines

| Semester 1 | Semester 2 |
| --- | --- |
| Calculus | Probability and Statistics |
| Linear Algebra | Data for Machine Learning |
| Python Programming | Introduction to Machine Learning |

| AI and Robotics | Sensors and Actuators |

- Semester 1 teaches mathematics, Python, physics, and AI and Robotics.
- AI and Robotics states the loop the later courses close: perceive, decide, act.
- The machines in that course are a robot arm, a mobile robot, and an aircraft.
- Physics of Motion starts from vectors and Newton’s laws.
- Semester 2 adds uncertainty, data, a first learning course, and sensors.
- Data for Machine Learning includes SQL and a dataset a model can train on.
- Object-Oriented Programming is the programming course after Python.

## YEAR 2 — Learning Systems and Motion

| Semester 3 | Semester 4 |
| --- | --- |
| Machine Learning | Deep Learning |
| Optimisation | Model Building and Evaluation |
| Signals and Systems | Software Engineering |
| Robot Mechanics | Applied Control Systems |
| Differential Equations | Simulation of Robotic Systems |
| Applied Machine Learning | Machine Learning Project |

- Semester 3 teaches classical machine learning beside Robot Mechanics.
- Robot Mechanics is position and velocity.
- Differential Equations is the mathematics the next semester’s controller is written in.
- Semester 4 adds neural models, Software Engineering, and Applied Control Systems on a simple plant.
- Simulation of Robotic Systems runs the machines in a twin and exports a labelled synthetic set.
- An aircraft is one machine in that twin.
- The machine-learning project is individual, presented live, and built beside the software-engineering course.

## YEAR 3 — Applied Artificial Intelligence

| Semester 5 | Semester 6 |
| --- | --- |
| Computer Vision | Computer Vision and 3D Data |
| Linux and Systems Programming | Natural Language and Generative AI |
| Dynamics of Autonomous Machines | Automation of Intelligent Machines |
| Real-Time Systems | Sensor Data Fusion |
| Human-Machine Interaction | Computer Vision Project |
| Vision Studio | Applied Intelligence Project |

- This is the hiring year. Machine learning, deep learning, and computer vision are complete, each with a project.
- Computer Vision uses a webcam or a phone camera, and includes a camera model, calibration, and detection.
- Linux and Systems Programming is the command line and enough C to read machine software.
- Real-Time Systems is software and timing in a simulator.
- Dynamics of Autonomous Machines is the rigid-body model: an arm, and one aerial machine with lift, drag, and the force and moment equations.
- Human-Machine Interaction is how a person directs and stops an autonomous machine. Airspace rules are one case in that course.
- Computer Vision and 3D Data is the second vision course.
- Natural Language and Generative AI teaches language models, and a unit that makes synthetic images for a detector.
- Sensor Data Fusion includes a Kalman filter on logged motion.
- Automation of Intelligent Machines uses a robot as the main machine and an aircraft as one more.

## YEAR 4 — Autonomous Intelligence

| Semester 7 | Semester 8 |
| --- | --- |
| Reinforcement and Imitation Learning | Reliable and Safe Learning |
| Robot Software | Physical AI: Perception to Action |
| Guidance and Navigation | Autonomy Project II |
| Multi-Robot and Swarm Systems | Technology and Society |

| Autonomy Project I | |

- Reinforcement and Imitation Learning trains one policy from a reward and one from demonstrations.
- Robot Software includes a flight stack when the machine is an aircraft. The work is in simulation.
- Guidance and Navigation includes path planning and SLAM. The swarm course uses that planner.
- Efficient AI Software runs a smaller model under a size and latency limit.
- Autonomy Project I sets up the twin and the task.
- Physical AI: Perception to Action turns a camera image and a short task into a command, scored in the simulator.
- Autonomy Project II uses the synthetic set, the policy, and that command.
- The result another person can check is a detection list, a map, or a route that changes when a zone is closed.
- The write-up states what would still have to be checked on a real machine.

# Your Degree. Your Timeline.

An award at the end of each year. A learner who stops can return to the next year. Courses already passed are not repeated.

| Exit point | Credits | Award | What is finished |
| --- | --- | --- | --- |
| After Year 1 | 36 | Foundation Certificate | Mathematics, Python, object-oriented programming, data, a first learning course, physics, and AI and robotics |
| After Year 2 | 72 | Diploma | Machine learning, deep learning, differential equations, robot mechanics, applied control, software engineering, and simulation, plus a machine-learning project |
| After Year 3 | 108 | B.Sc. in Artificial Intelligence and Autonomous Systems | Machine learning, deep learning, and computer vision with 3D data, plus natural language and generative AI, sensor fusion, and two further projects |
| After Year 4 | 141 | B.S. in Artificial Intelligence and Autonomous Systems | The B.Sc., plus imitation and reinforcement learning, a perception-to-action model, efficient AI software, and a defended autonomy project |

# Your Perspective Afterward

The work is practical: projects an employer can run, and machines practised in simulation. Graduates are prepared for artificial intelligence roles, and for robotics software where a machine has to perceive, decide, and act.

### AI Engineer (Machine Learning Engineer)

Develops applications that analyze data and enable automated decision-making.

### Robotics Engineer

Builds the software of robotic systems for industrial, logistics, or service applications.

### Software Developer Specialising in AI

Programs intelligent applications and integrates AI into existing systems.

### Human-Robot Interaction Designer

Makes collaboration between humans and robots usable and safe.

### NLP Engineer (Natural Language Processing)

Develops systems that understand, process, or generate language.

# Laboratories

A laboratory is not part of this curriculum, and it is not mandatory. Every course is completed online, in software and simulation.

The Aerospace Engineering department at IIT Kharagpur lists its facilities on the [department site](https://www.iitkgp.ac.in/department/AE). Two of those facilities are public:

- [Aeromodelling Lab](http://www.ae.iitkgp.ac.in/aeroweb/footerlinks/aero_model.php). Model building in composites, balsa, and thermocol, an engine test bench, and tools for model aircraft.
- [Computer Lab](http://www.ae.iitkgp.ac.in/aeroweb/footerlinks/comp_lab.php). Shared computers on the institute network, with Windows and Linux applications.

Neither lab is a course, a credit, or a required visit.

After a subject such as Dynamics of Autonomous Machines, Robot Mechanics, or Simulation of Robotic Systems, an instructor may use the Aeromodelling Lab for a live demonstration of a physical model. The demonstration is for the class to watch. It does not replace the simulation work, and a learner who does not attend it still completes the course.
