Re-Imagining Foundation Course

Using the enrollment-to-course-start window so every learner gets a persona-fit foundation path — planned sessions, mapped to existing SAL recordings, ready for automated scheduling.

Problem Statement

Learners often have unused time between admission and course start. Foundation content already exists across SAL, but it is not consistently packaged by persona and available duration. Without a clear track, students either skip foundations or get a one-size path that does not match their background or the weeks they have.

Solution

Re-imagine the foundation as duration buckets × persona tracks, with each session matched to existing SAL videos where content-fit allows. Stakeholder update: each relevant track now includes AI — Introduction to Gen AI and LLM.

  1. Bucket by time available — 1–4 weeks → 4-week track; 5–8 weeks → 8-week track; 9–12 weeks → 12-week track; and so on.
  2. Split by persona — Students & Working Different Field (WDF) share the beginner track; Working Same Field (WSF) is mid-Python / analytics-led.
  3. Match depth to wait time — a learner with 3 weeks and a learner with 7 weeks need different depth; each is mapped to a clear duration bucket instead of one shared path.
  4. Content Release: Existing SAL recordings will be reused — session planning uses the current inventory wherever a content-fit match is available.

Merits

  1. Individual engagement — Students can start and stay engaged individually; no need to wait for any foundation batch to begin.
  2. Course context by duration — Longer wait windows get fuller course context; shorter windows still get a solid foundation.
  3. Better experience & ratings — Overall learning and student experience improves, and instructor ratings may also rise in turn.
  4. Stronger foundations for outcomes — Strengthening foundations early may help placements in the future.
