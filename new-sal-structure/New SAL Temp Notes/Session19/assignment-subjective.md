# Assignment Subjective

## Task

Use this report. The fees, shares, date, and total are already stored. Do not rebuild the total.

|  | A | B | C | D |
| --- | --- | --- | --- | --- |
| 1 | Campus Fee Report |  |  |  |
| 2 | 24/09/2026 |  |  |  |
| 4 | Name | City | Fee | Share of total |
| 5 | Asha | Pune | 1000 | 0.05 |
| 6 | Imran | Delhi | 2000 | 0.10 |
| 7 | Neha | Pune | 3000 | 0.15 |
| 8 | Ravi | Kochi | 4000 | 0.20 |
| 9 | Lata | Pune | 10000 | 0.50 |

Question 1. A1:D1 is merged and centered. Name the cell that still stores the title text.
Question 2. Currency format is applied to C9. State what the formula bar shows.
Question 3. Percent format is applied to D9. State what the cell displays, and state what the formula bar shows.
Question 4. A different cell holds the number 50, and percent format is applied. State what that cell displays.
Question 5. A greater-than-4000 rule is applied to C5:C9. Name the stored fee that the rule highlights.
Question 6. State whether C8 is highlighted by that greater-than rule, and state why.
Question 7. A duplicate-values rule is applied to B5:B9. Name the city text that is highlighted, and name the city texts that stay plain.
Question 8. Data bars are applied to C5:C9. Name the stored fee that gets the longest bar.
Question 9. The print area is A1:D10. State whether a note in column Z is printed.
Question 10. State what Clear Rules removes, and name one kind of manual formatting it leaves in place.

## Answer Explanation

### Ideal answers

Question 1. A1
Question 2. 10000
Question 3. The cell displays 50%. The formula bar shows 0.50.
Question 4. 5000%
Question 5. 10000
Question 6. No. 4000 is equal to the cutoff, and greater than highlights only values strictly above 4000.
Question 7. Pune is highlighted. Delhi and Kochi stay plain.
Question 8. 10000
Question 9. No. The note stays on the sheet and is left off the paper.
Question 10. Clear Rules removes the conditional formatting rules. It leaves manual formatting such as bold, borders, or the currency format.

### Walkthrough

Merge and Center displays the title across A1:D1, but the text remains in the upper-left cell, A1.

C9 stores 10000. Currency format may show a rupee amount such as ₹10,000.00. The formula bar still shows 10000. C10 still stores 20000.

D9 stores 0.50. Percent format displays 50%. D5 stores 0.05 and would display 5%. The format does not divide the stored decimal.

A cell that already holds 50 is different. Percent format displays 5000% because it does not turn 50 into 0.50.

On C5:C9, the fees are 1000, 2000, 3000, 4000, and 10000. Only 10000 is greater than 4000. C8 stores 4000, so it stays plain. The rule does not change any stored fee. C10 is outside the selection.

Pune appears in B5, B7, and B9, so those three cells are highlighted. Delhi and Kochi appear once. The rule does not delete the extra Pune rows.

Among C5:C9, 10000 is the largest value, so it gets the longest data bar. 1000 gets the shortest. The formula bar of C9 still shows 10000.

The print area limits the paper to A1:D10. Fit to page can scale that block onto one page wide, and the on-screen column widths stay as they were set. Column Z is outside the print area.

Use Clear Rules when you want the colour, the scale, or the bars gone and you want the bold header, borders, and number formats kept. Clear Formats would remove that manual layout as well.

### Alternative

Accounting format is another valid rupee display for C5:C10. It lines the currency symbol up at the edge of the cell. The formula bar for C9 still shows 10000, the same stored value that Currency format leaves in place.
