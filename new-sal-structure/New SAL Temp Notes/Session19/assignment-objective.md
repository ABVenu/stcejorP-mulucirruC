# Assignment Objective

## Q1 (MCQ, Easy)

A cell holds 1000. A currency format makes the cell show a rupee amount. What does the formula bar show?

**Options:**
1. The fill colour of the cell
2. 1000%
3. The border style of the cell
4. 1000

**Correct:** 4

**Answer Explanation:**
The correct option is 4. A currency format changes the display. The stored amount stays 1000, so the formula bar shows 1000. The cell may show a rupee amount such as ₹1,000.00.

**Why other options are wrong:**
- Option 1: Fill colour is a look applied to the cell. It is not the value stored in the formula bar.
- Option 2: 1000% would be a percent display of a different stored value. Currency format does not turn 1000 into a percent.
- Option 3: A border is a line on a cell edge. It does not replace the stored number.

## Q2 (MCQ, Easy)

A cell holds 0.50. Percent format is applied. What does the cell display?

**Options:**
1. 5%
2. 50%
3. 5000%
4. 0.50%

**Correct:** 2

**Answer Explanation:**
The correct option is 2. Percent format displays the stored decimal as a percentage. 0.50 displays as 50%. The formula bar still shows 0.50. Applying the format does not divide the stored number.

**Why other options are wrong:**
- Option 1: 5% is the display for the stored decimal 0.05, not for 0.50.
- Option 3: 5000% is what you see if the cell holds 50 and percent format is applied. This cell holds 0.50.
- Option 4: The format does not leave the value looking like 0.50 with a percent sign stuck on. It shows 50%.

## Q3 (MCQ, Easy)

A greater-than rule uses the cutoff 4000 on the fees 1000, 2000, 3000, 4000, and 10000. Which fee does that rule highlight?

**Options:**
1. 10000 only
2. 4000 and 10000
3. 1000 only
4. Every fee in the list

**Correct:** 1

**Answer Explanation:**
The correct option is 1. Greater than is strict. Only 10000 is above 4000, so only that fee is highlighted. The stored numbers stay 1000, 2000, 3000, 4000, and 10000.

**Why other options are wrong:**
- Option 2: 4000 is equal to the cutoff, not greater than it, so it stays plain.
- Option 3: 1000 is below 4000, so this rule does not highlight it.
- Option 4: The rule does not paint every fee. 1000, 2000, 3000, and 4000 fail the test.

## Q4 (MCQ, Easy)

The cities in the selection are Pune, Delhi, Pune, Kochi, and Pune. A duplicate-values rule is applied. Which result is correct?

**Options:**
1. Only the second and third Pune cells are highlighted
2. Delhi and Kochi are highlighted because each appears once
3. All three Pune cells are highlighted, and Delhi and Kochi stay plain
4. The repeated Pune rows are deleted

**Correct:** 3

**Answer Explanation:**
The correct option is 3. A duplicate-values rule highlights every cell in the selection whose entry appears more than once. Pune appears three times, so all three Pune cells are highlighted. Delhi and Kochi appear once, so they stay plain. The stored text is still Pune, Delhi, or Kochi.

**Why other options are wrong:**
- Option 1: The rule does not skip the first copy. Every cell in the duplicate group is highlighted.
- Option 2: A value that appears once stays plain. The same dialog can mark unique values instead, but the duplicate choice marks the repeated cities.
- Option 4: The rule changes appearance only. It does not delete rows or merge them.

## Q5 (MCQ, Moderate)

A cell holds the number 5. Percent format is applied. What does the cell display?

**Options:**
1. 5%
2. 500%
3. 0.05
4. 50%

**Correct:** 2

**Answer Explanation:**
The correct option is 2. Percent format shows the stored number as a percentage. It does not divide a number that is already stored. A cell that holds 5 displays 500%. The formula bar still shows 5.

**Why other options are wrong:**
- Option 1: 5% would mean the stored value is 0.05. This cell holds 5, so the display is 500%, not 5%.
- Option 3: 0.05 is a different stored value. Applying percent format does not rewrite 5 as 0.05.
- Option 4: 50% is the display for the stored decimal 0.50. It is not the display for 5.

## Q6 (MCQ, Moderate)

Data bars are applied to the fees 1000, 2000, 3000, 4000, and 10000. Which statement is true?

**Options:**
1. 1000 gets the longest bar
2. 4000 is removed because it is the middle fee
3. The bars replace each stored fee with a new number
4. 10000 gets the longest bar

**Correct:** 4

**Answer Explanation:**
The correct option is 4. A data bar's length follows the value inside the selection. The largest value, 10000, gets the longest bar. The smallest, 1000, gets the shortest bar among these five fees. The formula bar still shows the stored fee.

**Why other options are wrong:**
- Option 1: 1000 is the smallest of these fees, so its bar is the shortest, not the longest.
- Option 2: Data bars do not delete a middle value. 4000 stays stored and gets a bar between the shortest and the longest.
- Option 3: The bar is a visual format. It does not write a new number into the cell.

## Q7 (MSQ, Moderate)

Which statements are true?

**Options:**
1. A currency format can show a rupee symbol while the formula bar still shows the plain number
2. A date format changes the stored day to a different day
3. Wrap text keeps the full stored label and can show it on more than one line
4. ##### in a narrow column means the value was deleted

**Correct:** 1, 3

**Answer Explanation:**
The correct options are 1 and 3. Currency format draws a symbol such as ₹ around the same stored number. Wrap text folds a long header inside the cell and can increase the row height. The formula bar still shows the full label.

**Why other options are wrong:**
- Option 2: A date format changes the pattern you see, such as 24/09/2026 or a longer month name. The stored date stays the same day.
- Option 4: ##### means the column is too narrow for the display. The value is still stored. Widen the column to see it. Do not retype the number.

## Q8 (MSQ, Moderate)

Which statements are true?

**Options:**
1. A print area leaves cells outside that range on the sheet and off the paper
2. Fit to page changes the on-screen column widths to the width of the paper
3. Bold on a header changes the look of the text and leaves the words the same
4. Merge and Center of A1:D1 keeps the title text stored in A1

**Correct:** 1, 3, 4

**Answer Explanation:**
The correct options are 1, 3, and 4. The print area is the range that prints. Other cells remain on the sheet. Bold does not rewrite the header words. Merge and Center shows the title across A1:D1, and the text stays stored in A1, the upper-left cell of the merge.

**Why other options are wrong:**
- Option 2: Fit to page scales the printout so the chosen width fits the paper. The on-screen column widths stay as you set them.

## Q9 (MSQ, Hard)

Which statements are true?

**Options:**
1. A greater-than-4000 rule does not highlight a cell whose stored fee is 4000
2. A colour scale maps the smallest and largest values in the selection to the two ends of a gradient
3. A colour scale rewrites the largest fee so that it becomes the smallest fee
4. Clear Rules removes conditional formatting and leaves manual formatting such as bold and borders

**Correct:** 1, 2, 4

**Answer Explanation:**
The correct options are 1, 2, and 4. Greater than is strict, so 4000 is not above 4000. A colour scale paints the low end and the high end of the selected numbers. It does not change those numbers. Clear Rules removes the conditional rule. Bold, borders, and number formats that you applied by hand stay in place. Clear Formats would remove that manual formatting as well.

**Why other options are wrong:**
- Option 3: A colour scale changes colours, not the stored amounts. The largest fee remains the largest fee in the formula bar.

## Q10 (MSQ, Hard)

Which statements are true?

**Options:**
1. Data bars change the stored number to the length of the bar
2. A cell that holds 50 displays 5000% after percent format is applied
3. A duplicate-values rule treats Pune and pune as the same text
4. A greater-than highlight leaves the stored number unchanged

**Correct:** 2, 3, 4

**Answer Explanation:**
The correct options are 2, 3, and 4. Percent format does not divide a stored 50, so the cell displays 5000% and the formula bar still shows 50. The duplicate comparison is not case-sensitive, so Pune and pune form one duplicate group. A trailing space would not match Pune. Highlighting does not write a new number. The formula bar still shows the fee.

**Why other options are wrong:**
- Option 1: A data bar is drawn inside the cell. The stored number stays the number you typed or calculated.
