title: Excel — Report Making: Basic & Conditional Formatting

objective: Make a fee sheet readable as a report with layout and number formats, then highlight values with conditional formatting without changing the stored numbers.

type of session: mixture of theory + implementation

topics be covered:
Column widths; bold header row; currency, percent, and date formats; borders; alignment; wrap text; a clear title row; print area and fit-to-page; conditional formatting for greater than, color scales, data bars, and duplicate values.

detailed subtopics to be covered:
Column width, a bold header, and a merged title row on a campus fee report
Currency, percent, and date formats, and the fact that the formula bar still shows the stored value
Borders, alignment, and wrap text
Print area and fit-to-page, including the desktop Page Layout path and File > Print on Excel for the web
Highlight Cells Rules greater than a cutoff, where equality is not highlighted
Color scales, data bars, and duplicate values, and Clear Rules so manual layout stays
A reminder that conditional formatting does not change the stored number or a total already calculated
