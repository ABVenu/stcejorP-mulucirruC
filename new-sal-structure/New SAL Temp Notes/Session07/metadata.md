title: Python — Lists & Strings

objective: Work with string indexing, slicing, and common methods, and with lists you can index, edit, and loop over.

type of session: mixture of theory + implementation

topics be covered:
string indexing; slicing; len; upper; lower; strip; replace; split; join; string immutability; list create; index; slice; append; insert; pop; remove; list len; list mutability; loop over a list

detailed subtopics to be covered:
Create a string and read one character by index, including a negative index
Slice with a stop that is not included, and measure text with len
Return new strings with upper, lower, strip, and replace
Split a line into pieces and join pieces with a separator
Explain immutability: methods do not edit the original string
Create a list, index it, slice it, and loop over it with for and while
Add and remove items with append, insert, pop, and remove
Contrast list mutability with string immutability
