title: SQL — Subqueries

objective: Nest one SQL question inside another using WHERE, SELECT, FROM, and a simple EXISTS test.

type of session: mixture of theory + implementation

topics be covered:
What a subquery is; subquery in WHERE with IN; subquery in WHERE with a comparison; scalar subquery in SELECT; subquery in FROM; EXISTS at a simple level; correlated versus non-correlated, in plain words, with one example of each.

detailed subtopics to be covered:
A subquery is a SELECT inside another statement, written in parentheses
IN keeps outer rows whose value appears in an inner list
A comparison such as > or = needs a scalar subquery that returns one value
A scalar subquery in the SELECT list adds one value without removing outer rows
A subquery in FROM is a derived table and needs an alias
EXISTS asks whether at least one inner row comes back
A non-correlated subquery can run alone; a correlated subquery refers to the current outer row
One contrast only: a join places tables side by side; a subquery nests a question
