# Assignment Objective

## Q1 (MCQ, Easy)

Which job is done by traditional software?

**Options:**
1. Drafting a birthday wish that was not stored in advance
2. Multiplying 5 by 5 because a multiply rule was programmed
3. Writing three new titles from a short project description
4. Producing a new three-line summary of text that was pasted in

**Correct:** 2

**Answer Explanation:**
Traditional software follows instructions a person wrote. A multiply rule already defines the result of 5 times 5, so the same allowed input produces the planned result.

**Why other options are wrong:**
- Option 1: A newly written wish is generated text, not a result fixed by a stored rule.
- Option 3: New titles are created text. A rule-based program does not invent those wordings.
- Option 4: A new summary is generated from the pasted text. It is not a single planned result stored in advance.

## Q2 (MCQ, Easy)

What does generative AI produce?

**Options:**
1. Only a fixed label, such as spam or not spam
2. One planned number that a written rule already defines
3. New text, such as a sentence, a summary, or a list
4. A live copy of every website at this minute

**Correct:** 3

**Answer Explanation:**
Generative AI creates new content. In this material, that content is text: sentences, summaries, or lists that fit the request. "Generative" means newly written. It does not mean the text is automatically true.

**Why other options are wrong:**
- Option 1: A spam-or-not decision is a classifier. It returns a label, not a new paragraph.
- Option 2: A planned number from a written rule is traditional software.
- Option 4: A generative text model is not a live copy of every website. If no source is shown, do not invent one.

## Q3 (MCQ, Easy)

What is a prompt?

**Options:**
1. The paragraph the model returns after you submit text
2. A password used to open the tool
3. One small piece of a word inside the model
4. The text you submit to start or steer the reply

**Correct:** 4

**Answer Explanation:**
A prompt is the instruction, question, or source text you submit. The model’s continuation of that prompt is the reply, which is a different thing.

**Why other options are wrong:**
- Option 1: The paragraph that comes back is the reply, not the prompt.
- Option 2: A prompt is ordinary language that names the job. It is not a password.
- Option 3: A small piece of text is a token. The prompt is the whole message you submit.

## Q4 (MCQ, Easy)

What is a token?

**Options:**
1. A small piece of text, such as a word, part of a word, a number, or a mark
2. A login password
3. The entire reply stored as one block that is never split
4. A coin or a fee paid for each question

**Correct:** 1

**Answer Explanation:**
A token is a small piece of text that the model reads and predicts. That piece may be a whole word, part of a word, a number, or a mark such as a full stop. A token is not always exactly one dictionary word.

**Why other options are wrong:**
- Option 2: A password is not the meaning of token here.
- Option 3: The model moves piece by piece. A sentence such as "The shop is open." can be several tokens, including the full stop.
- Option 4: Token here is a text piece, not a coin and not a fee.

## Q5 (MCQ, Moderate)

What is the basic move of a large language model?

**Options:**
1. It opens private files and copies a stored essay from them
2. It chooses a likely next piece of text, then another, until a reply is formed
3. It follows a written multiply rule and returns one planned number
4. It shows a live fare from a notice that was never provided

**Correct:** 2

**Answer Explanation:**
Next-word prediction chooses a probable continuation for the text so far, one small piece at a time. The reply is that chain of pieces. "Likely" is not the same as "checked and true today."

**Why other options are wrong:**
- Option 1: The model does not see files you did not provide, and it does not jump to one stored essay as its basic move.
- Option 3: A written rule with one planned result is traditional software, not next-piece prediction.
- Option 4: A likely sentence can name a fare and still be unchecked. The basic move is text continuation, not a live lookup you did not supply.

## Q6 (MCQ, Moderate)

A reply states that a bus fare is exactly ₹17 and has been that fare since 2019. That number was not in the prompt, and no notice is available to open. What is that failure called?

**Options:**
1. A grammar mistake only
2. A token
3. A prompt
4. A hallucination

**Correct:** 4

**Answer Explanation:**
A hallucination is output presented as fact when it is invented or unsupported by a source you can check. The confident fare was not given and cannot be opened in a notice, so it is unchecked invented detail. The smooth wording does not make the number true.

**Why other options are wrong:**
- Option 1: A grammar mistake is clumsy language. This failure can sit in perfect grammar and still be a false fact.
- Option 2: A token is a small piece of text, not the name of a false confident claim.
- Option 3: A prompt is the text you submit. The unsupported fare is part of the reply.

## Q7 (MSQ, Moderate)

Select every job these tools fit well.

**Options:**
1. Rewrite a rough sentence when the meaning is already yours
2. Summarise text that you paste into the prompt
3. Invent a citation for a paper you cannot open
4. Explain a term in simple words that you can compare with your own notes

**Correct:** 1, 2, 4

**Answer Explanation:**
These tools are strong at a first draft, simpler wording, and a summary of text you actually provided. An explanation is usable when you can compare it with notes you trust. In each of those jobs, you can see the source and edit the result.

**Why other options are wrong:**
- Option 3: Inventing a citation is a weak use. The named paper may not exist, and a confident reference is still unchecked.

## Q8 (MSQ, Moderate)

Select every correct statement.

**Options:**
1. A classifier returns a label, such as spam or not spam, rather than a new essay.
2. A large language model already knows your personal marks without being given them.
3. A large language model continues text from what you type. It is not a live copy of every website.
4. In this topic, a token means a password.

**Correct:** 1, 3

**Answer Explanation:**
A classifier chooses a label from a fixed kind of decision. A large language model is the text engine that continues and reshapes language from the prompt. "Large" refers to the amount of text used in training and the size of the model, not to a live copy of the web and not to a private record of your marks.

**Why other options are wrong:**
- Option 2: The model does not know marks, a hostel, or other private facts unless that information is provided. A new chat is not a diary of your files.
- Option 4: A token here is a small piece of text, not a password.

## Q9 (MSQ, Hard)

Select every correct statement.

**Options:**
1. The same prompt often produces similar wording that is not identical every time.
2. Telling the model to be accurate removes hallucinations.
3. A likely next piece is not the same thing as a fact checked against a source.
4. Leave out a number, name, or rule that was not in the prompt and not in a source you can check.

**Correct:** 1, 3, 4

**Answer Explanation:**
Generative tools often vary the wording of a reply, so the meaning has to be checked each time. The model continues likely text. A likely sentence can still be false today. Any specific number, name, or rule that you cannot point to in the prompt or in a real source should be deleted before you rely on it.

**Why other options are wrong:**
- Option 2: Asking for accuracy can make extra fiction less casual. It does not make hallucinations disappear. You remain the checker.

## Q10 (MSQ, Hard)

Select every correct statement.

**Options:**
1. A search box finds pages that already exist. A generative reply writes new sentences.
2. Perfect grammar shows that a stated fact is true.
3. A clearer prompt names the job and the shape of the answer, and the reply still needs a check.
4. The model can read a private file that was not included in the prompt.

**Correct:** 1, 3

**Answer Explanation:**
Search returns something that already exists and can be opened. Generation writes sentences that may never have been stored as that exact paragraph. A clearer prompt names the reader, the task, and the size of the answer, which makes the reply easier to use. The reply can still add a false detail, so you still read it.

**Why other options are wrong:**
- Option 2: Grammar is a strength of these tools. Truth is a separate check. A false fare can be written in perfect grammar.
- Option 4: The model cannot see a notebook, a marks file, or any other private text you did not put in the prompt.
