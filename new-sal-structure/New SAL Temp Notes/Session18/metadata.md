title: Excel — VLOOKUP, XLOOKUP & HLOOKUP

objective: Fetch an exact fee or city name with VLOOKUP, HLOOKUP, and XLOOKUP, including the leftmost-column limit and the approximate-match pitfall.

type of session: mixture of theory + implementation

topics be covered:
Why a lookup exists; VLOOKUP arguments (lookup value, table, column index, exact match FALSE); what happens when the lookup column is not leftmost; the approximate match TRUE pitfall; HLOOKUP across a row; XLOOKUP with lookup range, return range, and if not found.

detailed subtopics to be covered:
A lookup fetches a stored fee or city instead of calculating a new total
VLOOKUP with lookup value, table array, column index, and FALSE on a course-fee chart
The leftmost-column limit, #N/A for a missing exact code, and #REF! for an index outside the table
Why omitting FALSE, or typing TRUE, can return a neighbour on a code table
HLOOKUP with a row index to return a city name from the row below a code
XLOOKUP lookup range, return range, and if-not-found, including a return column to the left of the code
