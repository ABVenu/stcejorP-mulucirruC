title: Excel — Understanding the Excel Interface

objective: Recognise the Excel window and enter, edit, select, and rearrange cells without writing a calculation.

type of session: mixture of theory + implementation

topics be covered:
Workbook versus worksheet; ribbon and tabs; formula bar; name box; rows, columns, cells, and the A1 address; sheets; entering and editing data; selecting ranges; inserting and deleting rows and columns; column width so text is visible; zoom; freeze as optional navigation only.

detailed subtopics to be covered:
A workbook is the file; a worksheet is one grid chosen from the sheet tabs
The ribbon holds commands under tabs such as Home and View
The name box shows the active address; the formula bar shows what that cell stores
A cell address is the column letter then the row number, as in A1
Enter and edit values; Delete clears one cell and does not remove the row
Select a range such as A1:C4, or a whole row or column
Insert and delete shift the grid; addresses of existing values can change
Widen a column to reveal stored text; zoom and Freeze Top Row change the view only
