# Assignment Subjective

## Task

Use this grid. Answer each question from the original grid unless that question tells you to insert a row or a column.

|  | A | B | C |
| --- | --- | --- | --- |
| 1 | Name | City | Marks |
| 2 | Anita Shah | Pune | 88 |
| 3 | Rahul Iyer | Delhi | 76 |

Question 1. Name the address of the cell where column C crosses row 2.
Question 2. How many cells are in the range A1:C3?
Question 3. What does the name box show when C2 is the active cell?
Question 4. What does the formula bar show when A2 is the active cell?
Question 5. Using the original grid, insert a new row above the current row 2. Name the cell that then holds Anita Shah.
Question 6. Using the original grid again, with no row inserted, insert a new column at column A. Name the cell that then holds Pune.
Question 7. State what the Delete key does to one selected cell, and state what it does not do to the row.
Question 8. Anita Shah looks cut off because column A is narrow and B2 already has a value. State where the full stored text can still be read.
Question 9. State what Freeze Top Row does to row 1 while you scroll, and state whether that row can still be edited.
Question 10. State what zoom changes on the screen, and name one thing it does not change.

## Answer Explanation

### Ideal answers

Question 1. C2
Question 2. 9
Question 3. C2
Question 4. Anita Shah
Question 5. A3
Question 6. C2
Question 7. Delete clears that cell's contents. It does not remove the row.
Question 8. The formula bar
Question 9. Row 1 stays visible while you scroll. You can still edit row 1. Freeze Top Row does not hide the rows below.
Question 10. Zoom changes how large the grid looks. It does not change cell values, addresses, or the stored column widths.

### Walkthrough

The address is the column letter, then the row number, so column C and row 2 is C2. The name box shows that same address when C2 is active.

A1:C3 has 3 columns and 3 rows, so 3 × 3 = 9 cells.

The formula bar shows the stored contents. For A2 that text is Anita Shah, even if the column is too narrow to show the whole name on the grid.

Question 5 starts from the original grid. Inserting a row above row 2 pushes Anita Shah from A2 to A3. A2 becomes blank. The text is moved, not copied.

Question 6 also starts from the original grid. Pune begins in B2. A new column at A shifts column B to the right, so Pune is in C2. The row number stays 2 because no row was inserted.

Delete on one cell empties that cell only. The row number remains, and the cells below do not move up.

Freeze Top Row is a way to keep the heading on screen. It is not a lock. Click the header and you can still change it.

Zoom is the magnifying glass for your screen. Another person can open the same file at a different zoom and still see the same cells.

### Alternative

These answers name cells and rules. No formula is required. To make C2 active, you can click C2, or you can type C2 in the name box and press Enter. Both leave the stored value unchanged.
